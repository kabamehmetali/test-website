# Olive & Ember Restaurant Website

A multi-page restaurant website built with **Node.js**, **Express**, and **Tailwind CSS** classes (via CDN).

## Pages
- Home (`/`)
- Menu (`/menu`)
- About (`/about`)
- Contact (`/contact`)

All visual image placeholders use Unsplash URLs.

## Run locally
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
